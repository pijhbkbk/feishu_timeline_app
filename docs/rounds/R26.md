# R26 — 登录入口直达飞书

## 目标与边界

- 删除“系统页面 → 登录选择页 → 飞书”的多余交互层级。
- 顶部“登录”和未登录状态按钮一次点击直接请求后端飞书授权地址并跳转。
- 保留 `/login` 作为旧链接和直接访问的兼容入口，但页面只负责自动跳转，不再展示飞书/模拟登录选择表单。
- 不修改后端认证、权限、流程、数据库模型或 migration。初始本地轮次
  不部署；随后用户明确授权把所有最新改动部署 production、创建新的 RC
  并合并 `main`。历史 `v1.1.0-rc.1` 标签保持不变。

## 输入

- 用户提供的 2026-07-22 现网截图：主页面登录入口、登录选择页、飞书授权页。
- 基线：`release/r25-final-gate`，HEAD `1ea034c`，工作树初始 clean。

## 实现

- `apps/web/src/components/app-shell.tsx`
  - 顶部“登录”和“前往登录”在飞书可用时直接调用 `startFeishuLogin`。
  - 保留 `href="/login"` 作为渐进增强回退；直接请求失败时进入自动跳转入口重试并展示受控错误。
- `apps/web/src/app/login/page.tsx`
  - 删除登录选择、飞书二次按钮和模拟登录表单。
  - 未登录且飞书已配置时只触发一次自动 OAuth 跳转。
  - 已登录用户手工访问时返回工作台；飞书未配置或请求失败时展示明确错误。
- `apps/web/tests/playwright/regression.spec.ts`
  - 覆盖顶部登录直达飞书和旧 `/login` 自动直达两条路径。
- `apps/web/playwright.config.mjs`
  - 允许本机通过显式 `PLAYWRIGHT_EXECUTABLE_PATH` 使用已有浏览器；默认 CI 行为不变。

后端 mock-login 接口仍保留给本地自动化，但不再暴露在用户登录页面。
