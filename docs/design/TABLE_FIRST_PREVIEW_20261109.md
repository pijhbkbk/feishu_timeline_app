## 可操作入口

在仓库根目录运行 `node scripts/preview/table-first.mjs`，仅监听127.0.0.1:3499：

- `http://127.0.0.1:3499/#review`
- `http://127.0.0.1:3499/#production`

React组件在 `apps/web/src/features/table-first-preview/`；独立打包，不加入Next正式路由，不启动API或读取环境凭据。服务只返回3个固定静态文件，浏览器禁止业务连接。沿用已有依赖，不变锁文件。

页面顶部及工具栏标示“交互预览·合成数据”“仅本浏览器保存”。保存版本是预览存档版本，与正式业务版本无关。修改即时保留本机草稿，显式保存后读回，再提示已保存；保存失败不清除输入。跨标签检查存档版本，冲突草稿刷新后仍不能覆盖较新存档。清理浏览器数据会删除这份预览存档；可通过更多菜单导出JSON保留。

完整操作：增加两车 → 在表内选两色、填同一天/车身号/生产日期 → 连续录入四条评分 → 保存 → 月度产量首个月份格粘贴 `12\t0\t\n8\t9\t10\n0\t\t7` → 预览/确认 → 改一格 → 保存 → 刷新 → 色差页/产量页往返。更多菜单可选择独立空态、演示下一次保存失败或查看本机历史。
